# 🎓 Master's Project Management System

## 📌 Overview
This is a **group project** developed as part of the **Human-Computer Interface Design** course at **California State University, Sacramento**.  
The project focuses on streamlining the **Master’s Project process** with an easy-to-use and accessible interface for students.

Initially, the system was designed as a **mobile application**, but based on feedback and usability considerations, the design was later adapted into a **web-based application** for broader accessibility and convenience.

## 🎯 Project Goals
- Simplify and digitalize the process of Master's Project submission and tracking.  
- Provide an intuitive interface for students to manage documents, deadlines, and communication.  
- Create a **low-friction, accessible design** that aligns with HCI principles.  
- Enhance usability through **interactive prototypes** and user-friendly workflows.

## 📐 Design Process
Our team followed the **Human-Centered Design (HCD)** methodology:

1. **Problem Analysis** → Understanding pain points of students handling Master's Projects.  
2. **Research & Brainstorming** → Gathering requirements and identifying features.  
3. **Wireframing** → Low-fidelity sketches to map user flows.  
4. **Prototyping** → High-fidelity Figma prototypes (mobile + web).  
5. **Feedback & Iterations** → Peer reviews, adjustments, and refinements.  
6. **Final Deliverable** → Accessible **website prototype** tailored for CSU Sacramento students.  

---

## 📊 Key Features (Designed in Prototype)
- Student Dashboard (Project overview, status, deadlines)  
- Project Proposal Submission & Approval workflow  
- Communication portal with advisors  
- Document management for reports, drafts, and final submission  
- Timeline and Milestone tracking  
- Notifications & reminders for deadlines
